# Models
Jev is TypeSafe's flagship System One model. Endpoint: POST /v1/systemone (same for all models). Select with request field `model`.

## Current
| Jev 1.13 | `jev-1.13.0` |
| Price (per Btok / Mtok) | $42 / $0.042 |
| Rate limits | 250k tokens/sec · 1,200 req/min |
| Context | 64k/request; 32k for `state` + longest question |
| Input | Text only (string, object, or text array). No image/audio/video. |

- Price: charged on input tokens; output free.
- Rate limits: over limit → 429. SDKs retry with backoff; honor retry-after.
- Context: state ingested once; questions evaluated in parallel.
- Preprocess non-text into text/structured fields before `state`.

Rate limits may change dynamically under load. Higher limits: sales@typesafe.ai.

## Customizing
No fine-tunes/LoRAs. Shape answers via request: put proprietary material in `state`; encode rules in instructions/criteria; decompose into atomic questions and combine in code.

## Language / data
English best; other languages weaker — test. Not trained on customer traffic. See Legal for DPA / ZDR.

## List models
GET /v1/models — returns aliases your account can use. Versioned IDs still accepted.

# API
POST https://api.typesafe.ai/v1/systemone
Authorization: Bearer 
Content-Type: application/json

## Request
- state (required): string | object | array — content to evaluate
- model (required): e.g. "jev-latest"
- questions (required): map of id → Question

Example:
{"state":"Help! My payouts have been failing for 3 days.","model":"jev-latest","questions":{"is_urgent":{"type":"noul","instructions":"Does this convey urgency?"}}}

## Question types
All share type + instructions. instructions may be string|object|array (put question in one field, data in others; reference with backticks).

### noul (yes/no → probability of yes)
criteria optional: {true, false} descriptions.

### choice (pick one option)
criteria required: map of option → rubric (null ok). Max 255 options.
Returns choice + probabilities + confidence.

### score (ordered levels)
criteria required: array of level descriptions (2–10).
Returns score (can land between levels) + legend + probabilities + confidence.

## Response
{ model, answers: { : Answer }, usage: { input_tokens, output_tokens } }

### Answer types
- noul: {type:"noul", noul: 0..1}
- choice: {type:"choice", choice, probabilities, confidence}
- score: {type:"score", score, legend, probabilities, confidence}

## Errors
401 bad key · 422 validation · 429 rate limit · 529 overloaded
On 429/529: exponential backoff (SDKs do this by default).

# Build tip
Code owns workflow; Jev supplies typed judgments. Keep known rules/lookups/execution in code. Ask independent questions together (parallel). Use confidence/probabilities for routing — validate thresholds on your data.
